Electro Union — moduler

iframe-preview · copy-paste till Webflow

Varje modul nedan är laddad i en <iframe> med ?embed=1 — precis som det kommer se ut i Webflow CMS. Modulerna postar höjd automatiskt via postMessage (_shared/embed.js), så ramen justerar sig själv. Klicka "Embed-kod" under varje för copy-paste-snipet.

01Gate

Open standalone Open ?embed=1

"I approve this message"-counter, Roman columns, scroll-driven. Behöver Supabase för att visa nummer.

▸ Embed-kod (för Webflow) 
<iframe
  src="https://trollprinsessan.github.io/electro-union-modules/gate/?embed=1"
  title="Electro Union — Gate"
  style="width:100%;border:none;display:block;overflow:hidden"
  scrolling="no"
  height="800"
  loading="lazy"></iframe>
<script>
window.addEventListener('message', function(e){
  if(e.data && e.data.type === 'eu-resize' && e.data.height){
    document.querySelectorAll('iframe').forEach(function(f){
      if(f.src.indexOf('/gate/') > -1) f.style.height = e.data.height + 'px';
    });
  }
});
</script>

Höjden på varje <iframe> synkas automatiskt via postMessage. När vi hostar modulerna (t.ex. på Vercel) byt bara src. Alla 7 modulerna är standalone-sidor med sina egna assets — inga beroenden utanför _shared/.
